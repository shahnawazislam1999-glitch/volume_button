# Vol Power

Volume up / down / mute / slider + lock screen / power menu, right in the notification drawer.
Made for phones with broken volume and power buttons (OPPO F19 Pro+ / ColorOS).

## Build on GitHub
1. Create a repo, push this whole folder (the `.github` folder must be included).
2. Open the **Actions** tab -> "Build APK" (runs on push, or press "Run workflow").
3. When green, open the run -> **Artifacts** -> `VolPower-APK` -> download and install.

## First run (important for OPPO)
Open the app and tap buttons 1 to 6 top-down. See the checklist on the main screen.
